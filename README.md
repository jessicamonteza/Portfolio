# Jessica Montezas Portfolio

## Om min sida
Heej! Detta är min första portfolio jag bygger med kod, har designat det som en one-page med HTML, CSS och Javascript. Den ska efterlikna hur min nuvarande officiella portfolio ser ut ungefär: (https://jessimonteza.framer.website/). 

Denna Sidan innehåller navigation, intro section, project section och en about me section samt en ofärdig footer. Mina knappar leder till olika sektioner i sidan, och min resume leder till en googlde drive fil som har min CV.
