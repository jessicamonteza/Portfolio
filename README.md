# Jessica Montezas Portfolio

## Om min sida
Hej! detta är min portfolio som jag har byggt med hjälp av HTML, CSS och Javascript. Designen och innehållet är inspirerad av min nuvarande portfolio i framer Jessica Monteza – Portfolio.

Sidan innehåller navigation, en introsektion, projektsektion och en about me sektion samt en enklare footer.

## Interaktion med JS
* Read more/Read less: I min about section har jag en knapp som fäller ut för att visa mer text innehåll. Den är byggd med addEventListener, if och else samt classList för att dölja text.

* Hamburgarmeny: På mindre skärmar omvandlas navigations länkarna till en hamburgarknapp som fälls ut. Jag har använt liknand teknik som i read more/less knappen.

## Tillgänglighetsval
* Jag har användt sementiska HTML-element som header, nav, main, sections, article och footer där det har passat.
* Har lagt alt-texter på alla mina bilder så att det beskriver innehållet.
* Jag har lagt till fokusmarkeringar med :focus-visible så att det blir lättare att se var fokusen ligger när man navigerar med tangentbord.
* Kollade att färgkontrasterna var åtmisntone godkänd och applicerad rem där möjligt
